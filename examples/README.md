# 导入示例

## 四级词汇 Excel

下载 [cet4-vocabulary.xlsx](cet4-vocabulary.xlsx)，启动 OnlyWork，右键托盘 → **设置 / 导入题库** → **导入题库** → 选择该文件。
导入成功后，共 3,848 道单选题；每个单词对应一道四选一释义题，悬停圆盘左上角 **?** 可查看完整释义和词形变化，移开立即隐藏，在问号上滚轮可翻阅长解析。
导入后的题库会保存到应用的 `data/library.json`，关闭并重启程序仍可继续使用。

| 工作表 | 用途 |
|---|---|
| 轮盘题库 | 可直接导入；包含 ID、题目、A、B、C、D、正确选项、扩展；各选项独立一列 |
| 词汇表 | 按字母顺序查阅单词、音标、词性、完整释义与词形变化 |

程序优先读取当前选中的题库工作表；当前工作表不是题库时，会识别唯一含必需表头的工作表。
如同一文件含多张题库，先在 Excel 中选中要导入的工作表，再保存。
ID 为固定序号 1～3848，排序时随整行保留，不要重新编号。
「题目」单元格第一行是单词，第二行是音标和词性，可用 **Alt + Enter** 换行。
程序根据正确答案数量判断单选或多选。E、F 列可以按需增加，每题支持 3～6 个非空选项。
同一路径的题库重新导入保留进度；不同文件中的同号题目独立记录。

### 来源与范围

来源：[ECDICT](https://github.com/skywind3000/ECDICT) 的 `cet4` 标签全量词条。
数据版本：[`bc015ed2e24a7abef49fc6dbbb7fe32c1dadaf8b`](https://github.com/skywind3000/ECDICT/blob/bc015ed2e24a7abef49fc6dbbb7fe32c1dadaf8b/ecdict.csv)，整理日期：2026-10-08。
原始标记词条共 3,849 条；将 `reservior` 校正为 `reservoir`，将 `uptodate` 合并到已有的 `up-to-date`，最终 3,848 词。
`theatre`、`waggon`、`world-wide` 的音标采用同库对应变体；其余 7 个缺音标词条保留空白。

音标与完整释义沿用源词库；题目采用首项词性的前两条释义，并自动选择其他词条作为干扰项。
正确答案位置在 A / B / C / D 中各有 962 道。题目用于背词练习，未经考试命题审核。
这个范围不是官方四级大纲逐字版本，也不保证某一年度考试的全部用词覆盖。
词库以 MIT 许可提供，完整许可见 [LICENSE-ECDICT](LICENSE-ECDICT)，工作表内也保留了许可。

## 空白模板

[question-template.xlsx](question-template.xlsx) 的“轮盘题库”页为空，填写说明页包含单选、多选及解析示例。
也可在程序设置中选择“保存空白模板”。先另存为自己的文件，再填写并导入。
